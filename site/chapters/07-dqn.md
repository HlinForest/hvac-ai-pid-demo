# 07 DQN：用网络代替 Q 表

Q 表为每个离散格子单独保存动作价值。相邻格子之间不会自动共享经验。DQN 使用神经网络，根据连续观测预测九个动作价值，让不同观测通过同一组网络参数联系起来。

本章保留上一章的温控对象、九个动作、两分钟决策间隔和奖励。变化集中在价值函数的表示与训练方法上。

## 在 CPU 上运行

在已激活的 Python 环境中执行：

```bash
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m hvac_pid dqn
```

默认 500 回合，在 CPU 上训练。网络只有两个各 32 单元的隐藏层，结构为 `5 → 32 → 32 → 9`。基础实验没有导入这个模块，因此不安装 PyTorch 仍能运行 BO、FNN 和 Q-Learning。

## 网络读到什么

输入与 Q-Learning 相同：误差、误差变化率、上一控制输出、当前两项增益倍数。输入按固定尺度归一化，DQN 保留连续数值，Q-Learning 把它们离散分箱。

输出的九个数是动作价值，选最大值对应的动作。它们不是九个温度预测，也不是直接的制冷指令。PI 仍负责每 0.1 分钟产生输出。

动作价值相同时采用第一个最大值，与 Q 表的贪心评估规则一致。评估时关闭随机探索，网络权重保持不变。

## 经验回放：把最近发生的事保存下来

每执行一个动作，保存一条经验 $(s,a,r,s',done)$。回放池最多保存 10,000 条，两分钟产生一条。积累 256 条后，每次随机抽取 64 条训练。

这让一次更新可以包含不同回合、不同温控阶段的经验，而不是只反复拟合紧邻的几个时间点。它仍然只使用训练对象，没有从测试分区取经验。

## 目标网络：暂时固定右边的估计

当前网络预测 $Q_\theta(s,a)$，目标网络提供下一状态的最大价值：

$$
y=r+\gamma(1-done)\max_{a'}Q_{\theta^-}(s',a').
$$

训练只更新当前网络，目标网络不接收梯度。每完成 200 次梯度更新，再把当前网络的参数复制给目标网络。这里使用普通 DQN，不叠加 Double、Dueling 或优先经验回放。

例如这一步奖励是 -0.6，下一状态的最大目标价值为 -5，且回合没有结束，那么目标为 $-0.6+0.99\times(-5)=-5.55$。如果回合已经结束，目标就是 -0.6，不能再加后续价值。

算法机制也可对照 [PyTorch 官方 DQN 教程](https://docs.pytorch.org/tutorials/intermediate/reinforcement_q_learning.html)。本项目使用自己的温控环境和硬同步目标网络，直接查看本章源码即可知道实际运行方式。

## 动手：多训练一些再冻结

```bash
python -m hvac_pid dqn --episodes 1000 --seed 0 --output outputs/dqn-1000
```

比较最后训练回报、验证集 IAE、输出变化量和实际推理耗时。检查你看到的改善是否同时出现在冻结后的评估中。下一章转向另一种反馈利用方式：让大模型阅读试验结果，再提出下一组固定参数。
