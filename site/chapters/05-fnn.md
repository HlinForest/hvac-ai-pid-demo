# 05 FNN：把整定案例变成可复用的经验

BO 每遇到一个新对象，都需要重新做试验。如果已经为很多对象整定过，能不能先学习这些案例，再为新对象直接推荐参数？这一章用一个小型模糊神经网络（FNN）做这件事。

```bash
python -m hvac_pid fnn
```

脚本先生成 BO 教师标签，再训练网络。所有标签和对应试验保存在 `05-fnn/labels.json`，学到的规则后件在 `model.npz` 中。这个命令不需要 PyTorch。

## 一个案例长什么样

输入是阶跃辨识得到的三个数：$K,\tau,L$。输出是这个对象上 BO 找到的固定参数：$K_p,K_i$。网络不知道完整温度曲线，也不会在控制过程中持续修改增益。

对象范围为 $K\in[8,12]$、$\tau\in[12,32]$ 分钟、$L\in[1,5]$ 分钟。`experiments/splits.json` 预先划分 48 个训练对象、12 个验证对象、12 个测试对象。分区种子固定为 2026，改变算法种子不会重新分区。

只有训练对象用于拟合后件。验证对象用于选正则系数，最终的十二个测试对象留到第九章才评分。每组教师标签包含五个初始样本与十五次 BO 提案，生成标签的成本也计入 FNN。

## 三种隶属程度，组合成 27 条规则

把三个输入分别归一化。每个输入都有中心为 0、0.5、1 的三个高斯隶属函数，可以理解为该参数在训练范围内的低、中、高。

一条规则可能是：“增益偏高、时间常数中等、延迟偏低”。三个输入各有三种选择，一共 $3^3=27$ 条规则。规则强度等于三个隶属程度的乘积，再除以所有规则强度之和。

以归一化输入 $(0.5,0.5,0.5)$ 为例，每个输入对中间隶属函数的值是 1，对两侧约为 0.36。于是“中、中、中”规则最强，但旁边的规则仍参与预测。网络的输出随输入平滑变化，不需要先把对象硬分到某一个格子里。

## 学习的是规则后件

每条规则有两个待学习数值，分别贡献 log Kp 和 log Ki。归一化规则强度组成向量 $\bar w$，预测为：

$$
\widehat{\log K_p}=\sum_j\bar w_j c_{j,p},\qquad
\widehat{\log K_i}=\sum_j\bar w_j c_{j,i}.
$$

在 log 空间拟合，再取指数，预测参数自然为正。固定隶属函数后，后件训练就是带正则项的线性最小二乘。本课不再增加隶属函数训练、上下文残差网络或在线规则修补。

这种实现是固定前件、可学习后件的零阶 TSK 网络。它学习 BO 标签的规律，不是一套独立探索最优参数的算法。

## 动手：减少教师试验预算

```bash
python -m hvac_pid fnn --rounds 5 --output outputs/fnn-small-teacher
```

每个教师现在只有五个初始样本加五次新提案。比较生成时间、验证 IAE 和最终参数：减少教师成本后，网络预测效果怎样变化？不要根据测试集结果反复选择教师预算，验证集才是做这类选择的地方。
