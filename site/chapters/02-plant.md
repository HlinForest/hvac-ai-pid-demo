# 02 看懂对象：一个温度状态就够了

我们希望整定算法面对一个有惯性、有延迟的对象，又能让读者直接理解每个参数。这里用一个温度状态描述对象，不再分别追踪墙体、压缩机和传感器的动态。

## 先运行阶跃实验

```bash
python -m hvac_pid plant
```

程序让对象从 30℃ 平衡状态开始，将制冷指令从 0 提高到 0.5，并维持 240 分钟。打开 `02-plant/step.svg`，同时查看 `step.csv` 和 `identification.json`。

![改变增益、时间常数与延迟后的阶跃响应](/results/02-plant/step.svg)

四条曲线只改变一个参数。更大的制冷增益改变最终温度；更大的时间常数使整段变化变慢；更大的延迟把响应的起点向右移动。

## 三个参数分别控制什么

模型方程是：

$$
\tau\frac{dT}{dt}=T_{\mathrm{ambient}}+d(t)-T(t)-K u(t-L).
$$

| 量 | 默认值 | 含义 |
|---|---|---|
| $K$ | 8℃ | 单位制冷指令对应的稳态降温量 |
| $\tau$ | 20 min | 温度接近新平衡的时间常数 |
| $L$ | 2 min | 指令到温度响应开始之间的延迟 |
| $d(t)$ | 60 min 后为 1℃ | 持续热负荷对应的等效平衡温度增量 |

当指令是 0.5、没有扰动时，新平衡是 $30-8\times0.5=26$℃。输出改变后的头两分钟温度保持不变。再经过一个时间常数，完成总变化量的 $1-e^{-1}\approx63.2\%$，因此第 22 分钟的温度约为 $30-4\times0.632=27.472$℃。

这里的扰动用等效温度表示。它便于解释负荷变化，不对应某一台空调的实际功率或节电量。

## 每一步怎样计算

在一个采样区间内，假设延迟后的指令和扰动保持不变。先算该区间的平衡温度 $T_\infty$，再精确更新一阶响应：

$$
T_{k+1}=T_\infty+(T_k-T_\infty)e^{-\Delta t/\tau}.
$$

延迟用队列实现。步长 0.1 分钟、延迟 2 分钟，对应 20 个输入样本。第一个新指令在 $t=2$ 分钟开始作用，第一次受它影响的温度样本位于 $t=2.1$ 分钟。区分“区间起点”和“更新后的样本”，可以避免图上错位一格。

本课要求延迟是采样间隔的整数倍。改变延迟时可用 2.1、3.5 等值，程序不会默默舍入你输入的值。

## 从曲线辨识参数

整定函数得到的是阶跃数据。它不知道配置里真正的 $K,\tau,L$，用最小二乘拟合以下降温曲线：

$$
\Delta T(t)=0.5K\left[1-e^{-\max(t-L,0)/\tau}\right].
$$

## 动手：先判断，再改延迟

```bash
python -m hvac_pid plant --delay 5 --output outputs/delay-five
python -m hvac_pid temperature --delay 5 --output outputs/closed-loop-delay-five
```

第一条命令只观察对象。第二条把原来的手工 PI 放回同一个延迟更大的对象。比较温度响应，解释为什么“控制器已经改变了输出”不等于“温度已经反映出这个变化”。下一章把辨识结果代入经典整定公式。
