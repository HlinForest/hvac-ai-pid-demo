# 06 Q-Learning：在控制过程中调整参数

前面的方法在运行前选好 Kp、Ki，之后参数保持不变。现在让学习策略每两分钟看一次控制状态，再决定接下来用哪组增益。PI 仍以 0.1 分钟为间隔运行，学习策略不会直接输出制冷指令。

```bash
python -m hvac_pid qlearning
```

默认训练 500 回合，每回合控制一个从训练分区抽取的对象。训练完成后关闭探索，把冻结的策略放到默认对象上运行。

![Q-Learning 的训练回报与探索概率](/results/06-qlearning/learning.svg)

左边是训练时的回报，右边是探索概率。训练回报包含随机动作，也混合了不同对象，不应被当作固定对象上的最终测试曲线。最后会单独执行没有探索的评估。

## 一步对应两分钟

策略只观察五个量：当前温度误差、过去一个决策区间的误差变化率、上一控制输出、当前 Kp 相对初始 Kp 的倍数、当前 Ki 相对初始 Ki 的倍数。

它不能读取真实 $K,\tau,L$、未来扰动或延迟队列。由于观测中没有完整隐藏状态，这是一种部分可观测的状态表示，不能据此声称满足表格 Q-Learning 理论收敛的全部条件。

每个对象开始前做一次阶跃辨识，用 SIMC 给出锚点参数。后续动作从下表选一组**绝对倍数**：

| 动作 | Kp 倍数 | Ki 倍数 |
|---|---|---|
| 0 / 1 / 2 | 0.5 | 0.5 / 1 / 2 |
| 3 / 4 / 5 | 1 | 0.5 / 1 / 2 |
| 6 / 7 / 8 | 2 | 0.5 / 1 / 2 |

例如动作 8 总是把两个增益设为初始值的两倍。连续选两次动作 8，仍然是两倍，不会变成四倍。动作 4 表示选择原来的参数，是普通动作，不是失败后的回退。

## 奖励直接来自 IAE

选定动作后运行两分钟，把这段误差累加为 IAE，奖励取它的负值：

$$
r_t=-\sum_{k\in\text{本区间}}|e_k|\Delta t.
$$

如果二十个采样点的平均绝对误差是 0.3℃，这一步奖励就是 $-20\times0.3\times0.1=-0.6$。整回合奖励的和恰好是完整仿真 IAE 的负数。

## 看一次 Q 值更新

温度误差分五档，误差变化率分五档，输出分三档，当前增益组合分九档，得到 $5\times5\times3\times9=675$ 个离散状态。每个状态保存九个动作价值。

更新公式为：

$$
Q(s,a)\leftarrow Q(s,a)+\alpha\left[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\right].
$$

默认 $\alpha=0.15$、$\gamma=0.99$。终止状态之后没有后续奖励，因此最后一步的目标只等于当前奖励。注意：折扣训练目标略偏重较早的奖励，最终报告仍使用不折扣的 IAE。

## 动手：改变训练回合数

```bash
python -m hvac_pid qlearning --episodes 100 --output outputs/q-100
python -m hvac_pid qlearning --episodes 1000 --output outputs/q-1000
```

比较训练回报、验证集 IAE，以及冻结策略的实际曲线。增加回合数不保证每次都改善，因为状态分箱、探索过程和对象差异都会影响学习。不要只挑最好看的一次训练回报。
