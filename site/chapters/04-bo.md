# 04 BO：让每次试验决定下一次怎么试

我们已经有两组经典参数。现在让程序再试一些参数，但不逐格穷举整个平面。贝叶斯优化（BO）每做完一次仿真，就更新它对“哪些地方可能更好”的估计。

```bash
python -m hvac_pid bo
```

默认先运行 Z-N、SIMC 和三个随机参数，共五次仿真。随后进行十五轮 BO 选点，总计二十次仿真。打开 `04-bo/trials.csv` 和 `search.svg`。

![BO 参数选点与最佳得分变化](/results/04-bo/search.svg)

左图是参数平面，数字表示试验顺序，颜色表示实际 IAE。右图的点是每次试验的成绩，折线是截至当时最好的一次。折线不升高，只说明我们保留了历史最好值；新提出的参数仍可能比之前差。

## 为什么在对数空间里搜索

搜索范围为 $K_p\in[0.01,3]$、$K_i\in[0.0001,0.5]$。Ki 跨越几个数量级，在线性坐标中均匀撒点会很少探索较小的 Ki。程序先把增益取对数，再归一化到单位正方形中。

随机初始点、BO 的候选点都使用这个坐标。图中仍展示实际 Kp、Ki，便于直接放回 PI。

经典公式的初始结果不裁剪。在少数训练对象上，Z-N 参数会超出 AI 提案范围；这组已完成的观测仍提供给 BO 和 LLM。新的 AI 提案遵守上述范围。最终记录会明确最佳结果来自初始样本还是后续提案。

## 高斯过程提供两张地图

根据已观察的五个点，高斯过程预测每个位置的平均 IAE $\mu(x)$ 和不确定性 $\sigma(x)$。这里固定 Matérn 核的长度尺度为 0.3，不在每轮增加一套核参数优化。

![五个初始样本后的预测、标准差与期望改进](/results/04-bo/surrogate.svg)

左图是预测误差，越低越好。中图是预测标准差，越高表示当前样本对该处约束越少。白点是已经做过的仿真。留意预测很好和不确定性高的位置不一定重合。

这两张地图都来自模型估计。它们不能替代实际温控仿真，因此选出的点仍然必须运行一次，得到真实 IAE。

## 用期望改进挑下一点

设历史最佳值为 $J_{\min}$，目标是最小化 IAE。期望改进为：

$$
\mathrm{EI}(x)=(J_{\min}-\mu)\Phi(z)+\sigma\phi(z),\qquad
z=\frac{J_{\min}-\mu}{\sigma}.
$$

例如历史最好为 50，某位置预测均值为 48、标准差为 2，则 $z=1$，EI 约为 $2\times0.8413+2\times0.2420=2.1666$。这个值把“看起来更好”和“仍可能有惊喜”结合起来。

## 对照预测与实际结果

从第六次试验开始，记录里同时有预测均值、预测标准差和真实 IAE。找一轮预测明显偏低的试验：它不代表程序坏了，而是新数据修正了之前的判断。此处没有“这次变差，就换成 SIMC 运行”的分支。

这次默认运行中，第五个随机初始点已经得到最小 IAE，后续十五次 BO 提案没有超过它。因此图中的“最佳 BO 结果”来自整个搜索流程的初始样本，不能解释成高斯过程带来了额外提升。这也是值得保留的实验结果：下一次可以改变种子或预算，检查这种情况是否重复出现。

## 动手：多给五次机会

```bash
python -m hvac_pid bo --rounds 20 --seed 0 --output outputs/bo-25-trials
```

这会运行五个初始样本和二十次新提案，共二十五次仿真。相同种子保持前面的搜索过程一致。比较第 20 次和第 25 次仿真的历史最佳值：额外预算是否带来明显收益？
