## 遗留风险（未关闭）

- FNN 标签冲突依旧明显（log-RMSE 1.85），校准回放仅比 IMC 好约 1%，不足以宣称普遍优于 IMC。
- RL 校准目标 56.88 差于 IMC 的 51.02，部署门正确拒绝——RL 结论是“训练仍有瑕疵且未通过”，非“已修好并优于基线”。
- RL 状态维度不满足严格 Markov 性；奖励与报告综合目标的一致性未完全对齐。
- 正式结论需默认 48/16 工况、至少 5 个随机种子，报告均值/标准差/95% 置信区间与验收门通过率。
- 真实设备上线前需用 BMS/台架数据校准 3R2C/FOPDT、最低频率与启停约束，并把 Python 执行器约束同步到 MCU 安全层。
