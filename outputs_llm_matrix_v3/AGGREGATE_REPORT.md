## 读法与边界

- `部署=1` 表示 Agent 提出的候选通过了硬边界、±10% 信任域、多场景重复仿真、安全门与部署复核并优于基线；`部署=0` 表示宿主回退到调优 IMC，不是仿真发散。
- 不同难度（std/hard）的目标 J 不可跨行直接比较；hard 场景扰动更强，基线 J 本身更高。
- 本矩阵回答的是「LLM 能否在安全门内找到优于调优 IMC 的增益」，而不是「LLM 能否直接控制空调」——后者在本架构中被刻意禁止。
