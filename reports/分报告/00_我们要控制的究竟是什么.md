## 阅读路线

先建立问题地图：对象、七种方法、结果口径和仿真边界。

按下面的顺序阅读：

1. **问题**：先说清这一步想回答什么，避免把指标当成结论。
2. **准备**：列出前置章节、配置、数据来源和版本；本篇不运行新的训练批次，重点是读懂证据和口径。
3. **运行**：复制命令或读取封存产物，记录输出目录和随机种子。
4. **走查**：用一个具体数值代入公式，再对照实现中的关键几行。
5. **观察**：先读坐标、曲线和表格，再说明“发生了什么”和“这说明什么”。
6. **核对**：用容差、断言、哈希或独立验证判断复现是否成功。
7. **边界**：把已经证明、只作观察和仍待验证的内容分开写。

| 阅读检查 | 完成标准 |
|---|---|
| 输入明确 | 能说出本步使用的状态、参数、数据集或基线 |
| 中间过程可见 | 至少有一段数值演算、过程记录或关键代码 |
| 输出可核对 | 能定位到 CSV、图、日志、断言或封存目录 |
| 结论有边界 | 没有把仿真、replay、候选或稳定性误写成实体验收 |

## 这次要解决什么问题

我们手里有一台变频精密/机柜空调，任务只有一个：**把房间温度稳定在设定值附近**。控制器是 PI——根据当前偏差调制冷量。但 Kp、Ki 取多少？传统做法靠老师傅的经验公式，调一次管一辈子；房间一换、负荷一变，参数就未必合适了。

于是我们想回答一个很具体的问题：**能不能让程序自己找到合适的 PI 参数，并且在工况变化时依然稳得住？**

本项目把七种做法放进同一个虚拟机房里比较：从最经典的公式（Z-N、IMC），到离线自动搜索（BO、安全 BO、LLM Agent），再到在线自适应（FNN、RL）。每一篇教程只讲一种，最后在第 11 篇把它们放到同一张考卷上。

## 开始前准备什么

读这套教程不需要特殊背景，会跑 Python 命令就行。动手的机器需要 Python 3.10+，依赖一次装好：

```bash
pip install -r requirements.txt
```

全部实验的唯一事实源是 `experiments/manifests/v4.yaml`：场景数量、随机种子、算法参数、验收阈值都在里面。任何结果都可以定位到" manifest + 代码版本 + 数据批次"，对不上的数字不要信。

## 先看一张系统框图

![图 0-1 系统结构框图](../figures/fig1_系统结构框图.png)

> **看哪里**：信号从左向右走一圈：目标温度 → PI → 压缩机限制 → 空调房间 → 温度传感器 → 回到 PI。
> **发生了什么**：AI 不直接碰压缩机，它只负责给出 Kp、Ki；真正出力的是 100 ms 内环 PI 和压缩机限制器。
> **这说明什么**：所有"智能"都被关在参数层，执行层永远有保底——这是后面每一篇安全结论的前提。

三个时间口径不要混（`hvac_pid/timebase.py`）：Python 仿真 AI 周期 300 s、嵌入式演示 120 s、MCU 墙钟 2 s + 100 ms 快环。报告里凡写"每 2 s"指的都是 MCU 墙钟或演示口径，仿真训练用的是 300 s。

## 七算法一句话关系

| 算法 | 它在系统里的位置 | 输出 |
|---|---|---|
| Z-N 反应曲线法 | 上位机辨识 + 经验公式 | 固定 Kp/Ti（激进基线） |
| IMC-λ | 上位机模型整定，λ 扫描 | 固定 Kp/Ti（全项目的回退基准） |
| 贝叶斯 BO | 上位机离线搜索 | 固定 Kp/Ki |
| 风险感知安全 BO | 上位机风险 + 安全代理搜索 | 固定 Kp/Ki |
| FNN 在线自整定 | PC 训练规则面，MCU 查表 | 每 2 s 在线 Kp/Ki |
| RL 在线自整定 | PC 离线 Q 学习，MCU 查冻结策略 | 每 2 s 在线 Kp/Ki |
| LLM Agent | 上位机工具调用，只给建议 | 固定 Kp/Ki（须经仿真验收） |

建议顺序：01 → 02/03（先懂对象和规则）→ 04/05（经典基线）→ 06/07/10（离线自动整定）→ 08/09（在线自整定）→ 11/12（统一比较与部署）。算法篇可以独立阅读，但第一次读请按顺序走完 01–03。

## 仿真边界：先说清楚什么没证明

- 以上全部是**仿真 + 软件在环（SIL）**结果，不是真实空调房测出来的。SciPy 交叉验证证明的是数值实现一致，不是对象真实。
- Modelica 模型是历史证据，当前未复现；实体板遥测、真实 WCET、HIL 都是待外部验证（见第 12 篇）。
- LLM 的 replay 轨迹是离线录制，不是实时模型调用；真实调用看分布，不看单次。
